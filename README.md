# Kathmandu SMP Shop — Android wrapper

This is a Capacitor Android shell for the existing live Kathmandu SMP E-Shop.

- App name: Kathmandu SMP Shop
- Android application ID: `com.kathmandu.smp.shop`
- Live shop: https://kathmandu-minecraft-smp-e-shop-br6yqx.v2.appdeploy.ai/
- Build output: `android/app/build/outputs/apk/debug/app-debug.apk`

## Build an installable test APK with GitHub Actions

1. Create a new **private** GitHub repository.
2. Upload the contents of this folder to the repository (the `.github/workflows` folder must be included).
3. Open the repository's **Actions** tab.
4. Run **Build Kathmandu SMP Shop APK** (or push to `main`).
5. When the workflow finishes, open its run and download the `kathmandu-smp-shop-debug-apk` artifact.
6. Extract the artifact ZIP; install `app-debug.apk` on your Android phone. You may need to allow installation from that source.

## Important

- This is a native Android APK shell that loads the existing hosted shop. Orders, admin, tracking, and UPI remain on the existing backend.
- An internet connection is required.
- The workflow produces a **debug APK** for testing and direct installation. A Play Store release or production-signed APK requires a release keystore and secure signing configuration.
- Do not commit signing keys or passwords to the repository.
- The initial Android project is generated by Capacitor in CI, so the `android/` directory is intentionally not included.
- Replace the default Capacitor launcher icon with your approved shop icon before public distribution.
